# Fonti archivio personale ESEGUI / DOS

Materiale fornito dall'utente durante lo sviluppo di ComboCode:

- `comandi Esegui_dos.docx`
- `Comandi Esegui_Dos2.docx`
- `Comandi Esegui_Dos3.docx`

## Metodo di importazione v3

`Comandi Esegui_Dos3.docx` contiene la lista più estesa ed è stato usato come base di estrazione.

Le route già presenti nei pack moderni sono state deduplicate.

Le route nuove provenienti dall'archivio storico sono state inserite come **riferimenti non eseguibili**, con provenienza esplicita e uno dei seguenti stati:

- `Archivio utente — da verificare su Windows 10/11`
- `LEGACY — archivio Windows 2000/XP`

Il testo dell'archivio non viene silenziosamente modernizzato: prima viene conservato, poi potrà essere verificato e promosso a route corrente.
